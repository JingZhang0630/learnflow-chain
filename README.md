# LearnFlow-Chain

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24097495.svg)](https://doi.org/10.5281/zenodo.24097495)

Reference implementation accompanying the manuscript *LearnFlow-Chain: Task-Bound Purpose
Enforcement and Ledger-Anchored Provenance for Privacy-Preserving Cross-Institution Item
Calibration* (submitted to *Cluster Computing*).

The system calibrates item difficulty across institutions without pooling raw learner records.
Every federated round is admitted by an endorsed, purpose- and task-bound predicate on a
permissioned ledger; student-level differential privacy noise is added by each institution
(no trusted aggregator); and lineage from dataset version to published result is anchored as
digests, states and Merkle roots.

## Repository layout

| Path | Contents |
| --- | --- |
| `src/lfchain/` | Core Python package: policy engine, Merkle trees, zCDP budget ledger, Rasch calibration (CEN/LOC/CNT/FED/DP-FED), ledger adapters, dataset construction. |
| `chaincode/learnflow_audit/` | Hyperledger Fabric chaincode (JavaScript, chaincode-as-a-service): institution and dataset registration, task state machine, `CheckAccess`, model registration, Merkle anchoring, proof verification, audit history. |
| `fabric/gateway/` | Local HTTP bridge and load generator used by the Python code and Experiment D. |
| `experiments/` | One script per experiment; `make_paper_assets.py` regenerates every number, table and figure from `results/`. |
| `tests/` | Unit tests for the policy engine, Merkle proofs, DP accountant and calibration. |
| `results/` | Raw experiment outputs (JSON/JSONL/CSV/log) and the frozen hyper-parameters. Every number in the manuscript is generated from these files; none is entered by hand. |
| `paper/generated/` | Auto-generated LaTeX macros and tables. |
| `paper/figures/architecture.tex` | Editable TikZ source of the architecture figure. |
| `docs/` | Experiment protocol frozen before the runs, and the recorded deviations from it. |
| `learnflow-chain.tex`, `references.bib`, `figures/` | Manuscript sources (Springer Nature `sn-jnl`, MathPhys numbered style). |

## Reproducing the reported results

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=src pytest -q
PYTHONPATH=src python experiments/exp_ab_utility.py --help
PYTHONPATH=src python experiments/make_paper_assets.py   # regenerates paper/generated/
```

The Fabric-based experiments additionally require Hyperledger Fabric 2.5 and the Node
dependencies declared in each `package.json` (`npm install`). `docs/experiment_protocol.md`
records the frozen protocol, dataset splits, hyper-parameters and hardware environment
(`results/env.json`).

To rebuild the manuscript:

```bash
pdflatex learnflow-chain && bibtex learnflow-chain && pdflatex learnflow-chain && pdflatex learnflow-chain
```

## Data

The two real datasets, ASSISTments 2009--2010 and the Junyi Academy log, are **public but not
redistributed here**. Obtain them from their providers under their research-use terms and set `LEARNFLOW_DATA`
to their location (or pass the path as the first argument to `prep_junyi.py`); compact
caches are written under `data/` (excluded by `.gitignore`). `src/lfchain/data/prep_junyi.py`
converts the raw log into the parquet cache used by the experiments. Synthetic data are
generated by the code and describe no real persons. The chaincode stores identifiers, states
and digests only; no learning records are written to the ledger.
